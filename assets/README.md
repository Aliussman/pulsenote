# Demo Assets

Upload your screen recording or animated demo here so it displays directly in the root `README.md`.

### Recommended Formats:
1. **MP4 Video (Recommended for GitHub):**
   - Save your screen recording as **`demo.mp4`** in this directory (`assets/demo.mp4`).
   - GitHub markdown natively renders and streams `.mp4` video files with playback controls.

2. **Animated GIF (For instant auto-play):**
   - Save as **`demo.gif`** in this directory (`assets/demo.gif`).

3. **High-Res Poster / Screenshot:**
   - Save a still screenshot as **`demo_preview.png`** in this directory (`assets/demo_preview.png`).
